# ربات تلگرام سفارشی

نسخهٔ بازطراحی‌شده است: سیستم آپلود/لینک‌دهی فایل و دریافت فایل حذف شده است. امکانات:

- جوین اجباری با امکان افزودن/حذف کانال یا گروه و سفارشی‌سازی متن دکمه‌های عضویت/بررسی
- پیام شروع اعضا با چند متن، رسانه و فایل دلخواه
- دکمه‌های سفارشی اعضا در منوی پایین چت (Reply Keyboard)
- ارسال همگانی چندپیامه با پیش‌نمایش و تأیید نهایی
- ارسال بکاپ کامل SQLite به پیوی مالک در شروع ربات و سپس هر 24 ساعت

## تنظیمات

مقادیر محرمانه در فایل خصوصی `.env` قرار می‌گیرند. این فایل عمداً از Git، Docker image و ZIP پروژه کنار گذاشته شده است. اجرای محلی از طریق `main.py` یا `bot_app.py` فایل `.env` را می‌خواند. برای Docker، مقادیر را در Environment Variables سرویس میزبانی وارد کنید.

مالک باید یک‌بار در ربات `/start` بزند تا ربات اجازهٔ ارسال بکاپ به پیوی او را داشته باشد. اگر ارسال ممکن نباشد، ربات هر ساعت دوباره تلاش می‌کند.
